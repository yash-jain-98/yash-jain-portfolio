# Tool strip icons

Python, Excel, Power BI, Shopify, and WordPress SVG paths are from [Simple Icons 11.0.0](https://github.com/simple-icons/simple-icons/tree/11.0.0/icons), distributed under CC0. They are rendered in the portfolio’s existing single slate colour using `currentColor`. Brand marks remain the property of their respective owners. SQL uses a generic database symbol; AI Automation uses a custom processor/workflow symbol. Both are inline SVGs.
